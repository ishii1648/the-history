## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
ユーザー指摘（2026-07-26）: 地図が羊皮紙風の UI と別デザインに見える問題のうち、勢力ポリゴンの塗り色に起因する部分を扱う。ベースマップ（海・陸・背景）と線色の羊皮紙化は TASK-73 で行う。

現状（scripts/build-colors.ts:52-56 の実測値）: 色相を黄金角 137.508 度で 24 段に分散させ、SATURATIONS = [0.45, 0.60, 0.75]、LIGHTNESSES = [0.40, 0.52, 0.64, 0.76] の 288 色パレットから NAME の FNV-1a ハッシュで決定的に割り当てている（data/colors.json は 332 キー）。塗りの alpha は 0.5 相当（src/powers.ts）。この彩度・明度レンジのため、マゼンタ・紫・シアンなど羊皮紙の古地図にはあり得ない鮮やかな色相が地図上に現れる。CDP で撮影した 1200 年・1815 年のスクリーンショットで確認済み。

提案した変更（ユーザー承認済み。実装時に目視で微調整してよい）:
- SATURATIONS: [0.45, 0.60, 0.75] → [0.20, 0.30, 0.40]
- LIGHTNESSES: [0.40, 0.52, 0.64, 0.76] → [0.52, 0.62, 0.72, 0.82]
- 色相は黄金角 24 段のまま維持する（288 色の実効色数は docs/app-spec.md §4.3 の色衝突緩和要件であり削れない）

狙いは「色相の差は残したまま全体を褪せた顔料に寄せる」こと。彩度を下げ明度を上げることで、羊皮紙の下地（TASK-73 で earth を #f0e6cd 系にする）の上に乗せても浮かない配色にする。

トレードオフと注意点:
- 彩度を下げすぎると隣接勢力の識別性が落ち、alpha 0.5 の塗りでは陸地色に埋もれる。上記の彩度 0.20 は下限の想定であり、生成後に勢力が密集する年代（1200 / 1500 / 1815 など）で目視確認して詰める必要がある。
- 変更は data/colors.json の全 332 キーに及び、全 20 年代の見た目が変わる。属領（NAME|SUBJECTO の複合キー）は宗主国の色相に寄せた明度違いで生成されるため、明度レンジを上へ寄せると宗主国と属領のコントラストが縮む点も確認すること。
- HRE 領邦オーバーレイ（TASK-19 / 32 / 68）も同じ colors.json を参照するため、領邦同士の識別性も確認対象に含める。
- 色の割り当てロジック自体（FNV-1a ハッシュ・黄金角分散・SUBJECTO の扱い）は変更しない。定数の変更と再生成に留める。
