## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
1815 / 1880 / 1900 / 1914 の地図では base（europe_<year>.geojson）が United Kingdom of Great Britain and Ireland を単一 feature として持つため、スコットランド・アイルランドの区分が一切見えない。これは主権国家としては史実どおり（1707 年合同法・1801 年合同法）だが、ユーザーからは「ブリテン諸島が一括りで区別できない」と見える。

OpenHistoricalMap（CC0）には UK 内部の構成国が admin_level=4 のリレーションとして存在し、2026-07-30 の Overpass 実測で以下の実在とジオメトリの健全性を確認した（調査レポート: .outputs/claude/britain-split-feasibility.md）:
- Scotland（2697543: 1707-05-01..1891-05-14 / 2874398: 1891-05-15..1988-01-31）
- England and Wales（2697737: 1707-05-01..1891-05-14 / 2874397: 1891-05-15..1967-07-26）
- Ireland（2697728: 1801-01-01..1919-01-21）

ただしこれらは主権政体ではなく一国の内部区分であり、諸侯領オーバーレイ（封建的な従属関係を持つ領邦）とも意味論が異なる。本アプリが描いてきた「勢力」の定義に対して構成国を同列に置くと、1815 年以降だけ粒度が変わることになる。したがって実装の前に採否と表現方法を decision として決めることを本タスクの主眼とする。

判断すべき点:
- 構成国を採用するか（採用しない選択も正当な結論とする）
- 採用する場合、勢力レイヤーと同列に描くのか、境界線のみの別レイヤーとするのか、凡例・クリックパネルでどう区別するのか
- 1815 年以降に限って粒度が変わることをユーザーにどう伝えるか

既知の制約:
- ウェールズ単独の分離は不可。OHM は 1707〜1967 を England and Wales という単一の法域として持ち、Wales 単独のリレーションは 1967 年以降しか存在しない。これは史実（1536 年併合法以降イングランドと同一法域）と整合する。
- Scotland（admin_level=4）のリレーションの bbox 北端は 59.46 度で、シェトランド諸島（〜60.9 度）を含まない。採用する場合はこの欠落を既知の制限に記載する必要がある。
