## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
## 症状（bug）

**再現手順**: 年代を 1100 年にして中欧（プラハ周辺）を表示する。1200 年も同様。

**期待挙動**: ボヘミアが神聖ローマ帝国の版図に含まれて見える（1100 年は帝国の
封建諸侯領たるボヘミア公領、1200 年は同じく帝国内のボヘミア王国）。

**実際の挙動**: base（europe_1100 / europe_1200）でプラハ・ブルノを含む
ボヘミア・モラヴィア一帯が単一の Poland ポリゴンに塗り込められており、
帝国の範囲から外れて見える。1100 年は諸侯領オーバーレイ側に
Duchy of Bohemia（SUBJECTO=Holy Roman Empire）が乗るが、その下の base は
ポーランド領のまま。

**発見契機**: ユーザーによる目視確認（1100 年）。

## 調査済みの事実

プラハ (14.42E, 50.08N) / ブルノ (16.61E, 49.19N) を各年代の base で
point-in-polygon 判定した実測:

- 1000: Holy Roman Empire（正）
- **1100: Poland（誤）**
- **1200: Poland（誤）**
- 1279 / 1300 / 1400 / 1492 / 1500 / 1530 / 1600 / 1650 / 1700: Holy Roman Empire（正）
- 1715 以降: Austrian Empire / Austria Hungary（正）

つまり誤りは 1100 と 1200 の 2 年代に限局する。史実では 1100 年のボヘミアは
ボジヴォイ 2 世が統治する帝国内の公領、1200 年はプシェミスル・オタカル 1 世
（1198 年に王号取得、1212 年の金印勅書で確認）が統治する帝国内の王国であり、
いずれもポーランドの領域ではない。上流 historical-basemaps の帰属の誤り。

なお 1100 年の hre_fiefs 側は NAME=Duchy of Bohemia / SUBJECTO=PARTOF=
Holy Roman Empire で史実どおり。称号「公領」は 1100 年時点では正しい
（ヴラチスラフ 2 世の王号 1085 年は一代限りで 1092 年に消滅している）ため、
称号の付け替えは不要。

## 是正手段の見通し（実装時に再確認すること）

decision-28（base 帝国塗りに埋もれた封土は BASE_FIEF_SPLITS + propertyFixes）と
同型の事案。ただし切り出し元は Holy Roman Empire ではなく Poland。

- 1100: OHM 由来の data/hre_fiefs_flat_1100.geojson に Duchy of Bohemia
  （OHM_RELATION_ID 2805282）があるため、BASE_FIEF_SPLITS で Poland から
  切り出して feature を立て、SUBJECTO / PARTOF = Holy Roman Empire を
  propertyFixes（data/name-overrides.json）で年号付き note とともに宣言できる。
- 1200: OHM の Duchy of Bohemia は 1100 年のみ、Cliopatria の
  Kingdom of Bohemia も許可リスト上は 1279 以降で、scripts/build-cliopatria-fiefs.ts
  の解説は「Cliopatria は 1000〜1200 の帝国を一枚岩でモデル化しており内部領邦の
  feature が無い」としている。切り出しに使える出典付き区画が本当に無いかを
  上流原データで実測し、無ければ decision-14 / decision-18 に従い形状を合成せず
  data/known-limitations.json に明記して残す。区画があるなら 1100 と同じ手順で
  切り出し、称号は「ボヘミア王国」とする。
