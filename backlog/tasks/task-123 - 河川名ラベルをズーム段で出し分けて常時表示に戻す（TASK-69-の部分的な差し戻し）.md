## 背景・目的

TASK-69 で河川名ラベルの常時表示をやめ、ホバー／クリック時のみの表示にした。その理由は description に書かれたとおり「全河川の名前ラベルが地図上に常時表示されており、地図が煩雑になっている」の一点で、構造的・技術的な却下理由は無い。AC#4 の「国名・都市名ラベルの表示・衝突制御が退行しない」も共有衝突空間への配慮であって、河川ラベル自体を否定したものではない。

TASK-122 で諸侯領・帝国領邦のラベルを低ズームで出さなくなると、地図上の常時ラベルは大きく減る。実測した候補件数は次のとおり（同名分割を集約した後の実質ラベル数）。

| 年代 | 現在の政治ラベル候補 | うち領邦（TASK-122 で低ズーム時に消える） | TASK-122 後 | 河川 30 を戻した場合 |
| --- | --- | --- | --- | --- |
| 1000 | 97 | 44 | 53 | 83 |
| 1200 | 108 | 62 | 46 | 76 |
| 1300 | 129 | 91 | 38 | 68 |

河川は data/rivers.geojson に 48 feature あるが、同名の分割パートは filterVisibleRiverLabels が最高 priority の 1 件へ集約するので実質 30 ラベル。1300 年でも 129 → 68 と現在の半分近くに収まる。TASK-69 が問題にした密度は解消しているので、河川名を地図上に戻してよい。

## 方針: 二値の常時 ON ではなくズーム段で出し分ける

ズーム 4 はヨーロッパ全域が入るため、二値で戻すと 30 本の河川ラベルが常に全部競合する。またこの地図の点情報は既に全てズーム段で出し分けており、河川だけ二値だとこの体系の唯一の例外になる。

| 対象 | 現在の出し分け |
| --- | --- |
| 都市 | src/cities.ts visibleCityRankLimit（z4 以下=既定 / z5=40 / z6=80 / z7=160 / z8=∞。TASK-66） |
| 山脈 | Natural Earth の MIN_LABEL をアプリのズーム段へ写像（TASK-97） |
| 山峰 | filterVisiblePeaks（TASK-99） |
| 諸侯領・帝国領邦 | TASK-122 で追加 |
| 河川 | 無し（ホバー／クリック時のみの二値） |

素材は既にある。src/rivers.ts の riverLabelPriority が round(100 * log10(全パート合計長)) で長さ由来の priority を持つので、ライン川・ドナウ川・ロワール川のような大河はズーム 4 から、細かい河川はズーム段が上がってから、という出し方ができる。

## 対象

- src/rivers.ts の filterVisibleRiverLabels に、ホバー／選択に加えて「ズーム段に応じた priority 上位の常時表示」を返す経路を足す
- src/main.ts の buildRiverLabelLayer が zoomStep を受け取り、memo キーに含める
- 常時表示ぶんの通常色を決める（現在は表示＝ホバー／選択時なので強調色しか無い）
- riverLabelAnchors（アンカー生成・memo 化）は変更しない。TASK-50 の「ホバーを連続して動かしてもアンカー再計算が走らない」非退行を維持する

## 実装時に判断する点

- しきい値の設計。都市と同じくズーム段ごとの表示件数上限にするか、priority の絶対値でしきいを引くか。実機で 1000 / 1200 / 1300 年の zoom 4〜6 を見て決める
- **通常色の選定**。山脈の苔緑（MOUNTAIN_LABEL_COLOR、色相 139 度）・諸侯領の藍紫（FIEF_LABEL_COLOR）・帝国領邦の臙脂・都市名と色相が衝突しない値にする。河川ラインの色との関係も見る
- **ホバー時の二重表示**。常時表示に戻すと、ホバーした河川は「中点のラベル」と「カーソル脇のツールチップ」で必ず二重に出る。TASK-69 の Implementation Notes は「ツールチップ残置と判断（カーソル直下の即応表示と川中点の注記で役割が異なる）」としており、TASK-69 以前の状態に戻るだけだが、この判断を維持するかを再確認して Implementation Notes に記録する
- ホバー／選択中の河川は、ズーム段のしきい値で隠れる河川であっても必ず表示する（現在の挙動の非退行）
- 常時表示に戻すことで国名・都市名・山岳名ラベルが押し出されないか。共有衝突空間なので TASK-69 AC#4 と同じ観点で確認する

## 前提

TASK-122（低ズームでの諸侯領ラベル抑制）のマージ後に、低ズームの実際の見え方を確認してから着手する。同一 PR にすると「領邦を消してどれだけ空いたか」の効果を切り分けられなくなるため、依存を張って順に進める。
