## Description

## 背景・目的

タイムラインの最古年を 1000 年にし、900 年のスナップショットを廃止する。

900 年は他の年代と情報量が揃っていない。諸侯領オーバーレイが 4 系統とも対象外で（仏は OHM に有効な諸侯領が Anjou / Maine の 2 件しか無く面として成立しない、HRE は admin_level 4/5 の領邦が 1 件のみ、伊は admin_level 3/4/6 の面が 0 件、Cliopatria も内部領邦が乏しい）、フランス王国も神聖ローマ帝国も一枚岩の塗りでしか表示できない。1000 年以降で積み上げてきた領邦オーバーレイ・出典表示・被覆率の枠組みが 900 年だけ成立しない状態が続いている。

なお src/config.ts の INITIAL_YEAR は既に 1000 なので、本タスクの変更は初期表示ではなくタイムラインの選択可能範囲と関連データの削除である。

## 対象（実測で洗い出した参照箇所。着手時に再確認すること）

年代定義
- src/config.ts の SNAPSHOT_YEARS 先頭の 900 を削除する。HRE_FIEF_OVERLAY_YEARS / ITALY_FIEF_OVERLAY_YEARS / CLIOPATRIA_FIEF_OVERLAY_YEARS はもともと 900 を含まない
- src/config_test.ts に SNAPSHOT_YEARS の期待値と「900 を含まない」旨の既存テストが複数あるため整理する

データ
- data/europe_900.geojson を削除する
- data/index.json の years 配列から 900 を削除する（生成物なので再生成する）
- data/notes.json の years."900"（900 年の歴史解説）を削除する
- data/cities.json の 900 年エントリを削除する
- data/known-limitations.json の hre-territories-pre-1500 は years が {from:900,to:900} で 900 年専用のため、項目ごと削除する。text に 900 を含む他の項目（england-ireland-wales-1530-1700 / france-fiefs-missing-territories / base-unattributed-areas / base-attribution-snapshot-drift / base-nominal-suzerainty）は 900 年への言及が残ってよいか個別に判断する

スクリプト
- scripts/build-data.ts ほか、生成対象年を SNAPSHOT_YEARS から引いているパイプラインが 900 を取りに行かなくなることを確認する
- scripts/build-hre-fiefs.ts の HRE_FIEF_EXCLUSIONS.year900、scripts/build-france-fiefs.ts / build-italy-fiefs.ts / build-cliopatria-fiefs.ts の「900 は対象外」の根拠コメントは、900 自体が消えることで役割が変わるため記述を見直す
- scripts/build-cities.ts・build-attribution.ts・各 *_test.ts の 900 参照を整理する

ドキュメント
- docs/data-inventory/year-900.md を削除し、docs/data-inventory/README.md の年代一覧・実測表から 900 を外す
- src/timeline.ts・src/powers.ts・src/fief_dedupe.ts・src/approximate_borders.ts・src/main.ts のコメントにある「上=古い 900」「非対象年（900・1500 以降）」等の記述を更新する

## 実装時に判断する点

- 既存の共有 URL（?year=900 等）が開かれたときの挙動。src/url_state.ts の年代バリデーションが 1000 へフォールバックするか、無効値として初期年に倒れるかを確認し、壊れないことをテストで固定する
- 900 年に言及する known-limitations の本文をどこまで書き換えるか（900 年が選べなくなった後も歴史的経緯として残す価値がある記述と、意味を失う記述の切り分け）
- upstream（historical-basemaps）から europe_900.geojson を取得しない形にビルドを変えるか、取得はするが出力しないか
