# decision-34: 1815 年以降の UK 構成国は表示しない（内部行政区分は「勢力」として扱わない）

## Context

1815 / 1880 / 1900 / 1914 年の base（`europe_<year>.geojson`）は
`United Kingdom of Great Britain and Ireland` を単一 feature として持ち、
スコットランド・アイルランドの区分が見えない。ユーザーからは
「ブリテン諸島が一括りで区別できない」と映る。

OpenHistoricalMap（CC0）には UK 内部の構成国が `admin_level=4` の
リレーションとして実在し、ジオメトリも健全であることを実測済みである
（Scotland 2697543 / 2874398、England and Wales 2697737 / 2874397、
Ireland 2697728）。つまり**技術的には表示できる**。判断すべきは
「描けるか」ではなく「本アプリの勢力モデルに載せてよいか」である。

なお 1707 年合同法より前のブリテン諸島の分立は、#151 / #172 で既に
表示済みである（ウェールズ諸王国・アイルランド諸王国 1000〜1279、
アイルランド王国 1600〜1700 など）。本 ADR が扱うのは 1815 年以降に限る。

## Decision

**1815 年以降の UK 構成国（Scotland / England and Wales / Ireland）は
表示しない。**理由は次の 3 点である。

1. **勢力モデルとの層の違い**: 本アプリが描いてきた「勢力」は主権政体と、
   その封建的・名目的な従属関係（SUBJECTO / PARTOF の宗主）である。
   1801 年合同法以降の構成国は**一主権国家の内部行政区分**であり、
   この層に属さない。#189 でフィンランド大公国を独立表示したのは、それが
   ロシア皇帝を大公として戴く**別個の政体**（同君連合）だったからであり、
   UK 構成国とは性格が異なる。
2. **粒度の一貫性**: UK だけ内部区分を出すと、同時代の複合国家との整合が
   崩れる。オーストリア＝ハンガリー二重君主国・ロシア帝国の諸県・プロイセン
   の州はいずれも一括で描いており、UK にのみ第 1 級行政区分を与える原則的な
   理由がない。「描けるデータがあるから描く」は ADR-0014 / ADR-0018 が
   退けてきた態度と同型である。
3. **1815 年以降の一括表示は史実として正しい**。1707 年・1801 年の合同法に
   より、この時期のブリテン諸島は単一の主権国家である。単一ポリゴンで描く
   ことは欠落ではなく、地図が主張すべき内容そのものである。

**採用しなかった代替案:**

- **勢力レイヤーと同列に描く**: 上記 1 に反する。凡例・クリックパネルで
  「これは勢力ではない」と注記しても、色とクリック挙動が同じである限り
  利用者は同列に受け取る。
- **境界線のみの別レイヤー**: 勢力モデルは汚さないが、UK 1815 年以降だけに
  存在する層を新設することになり、上記 2 の恣意性は解消しない。

## Consequences

- `data/known-limitations.json` に 1815〜1914 年の年代連動エントリを置き、
  「この時期のブリテン諸島は単一の主権国家であり内部区分は表示しない」
  という方針と、1707 年以前は分立が表示されることを利用者に伝える。
  Wales 単独の分離が不可であること（OHM は 1707〜1967 を England and Wales
  という単一法域として持ち、これは 1536 年併合法以降の史実と整合する）と、
  Scotland リレーションの bbox 北端が 59.46 度でシェトランド諸島を含まない
  ことも、この判断の傍証として記録する。
- **判断が変わる条件**: 全ての複合国家について第 1 級行政区分を一貫して
  扱う枠組み（例: 「内部区分レイヤー」を勢力とは別の表現・別の凡例で持ち、
  UK もオーストリア＝ハンガリーもロシアも同じ規則で描く）を導入する場合は、
  本 ADR を superseded にして新しい ADR を書く。UK 単独の追加では覆さない。
- データ・コードの変更は生じない（表示しない決定のため）。既存の
  `britain_fiefs` 系統（1707 年以前）には影響しない。
