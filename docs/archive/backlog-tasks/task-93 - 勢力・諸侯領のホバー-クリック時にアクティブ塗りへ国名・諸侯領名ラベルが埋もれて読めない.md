## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
## 概要

ユーザー報告（2026-07-27）: 勢力・諸侯領のポリゴンをホバー/クリックすると TASK-90 のアクティブ塗り（緑青）が当たるが、その上に載る諸侯領名・国名ラベルが暗色のままのため文字が塗りに埋もれて読みづらくなる。強調で「どこを指しているか」は分かるようになった一方、「それが何か」を示すラベルが読めなくなっており、TASK-38 / TASK-54 / TASK-72 で積み上げたラベル視認性が強調状態でだけ後退している。

## 再現手順

1. アプリを起動し任意の年代を表示する（例: 1700 年）。
2. 地図上の勢力ポリゴン、または仏諸侯領・HRE 領邦のポリゴンにマウスカーソルを乗せる（またはクリックして選択状態にする）。
3. 強調された領域の上に描かれている国名・諸侯領名ラベルを読む。

## 期待挙動

強調中でも国名・諸侯領名ラベルが通常時と同等以上に判読できる。

## 実際の挙動

アクティブ塗りが暗い緑青でほぼ不透明なため、暗色のラベル文字が塗りに沈んで判読しづらい。とくに諸侯領名（藍紫）が読めない。

## 発見契機

TASK-90（ホバー/クリック時のアクティブ変色）マージ後の利用時にユーザーが報告。

## 調査済みの事実（起票時点。実装時に再確認し鵜呑みにしないこと）

- src/power_highlight.ts の ACTIVE_FILL_COLOR は [46, 110, 102, 214]（緑青）。通常塗りの FILL_ALPHA = 128（src/powers.ts）より大幅に不透明で、勢力固有色（colors.json）をほぼ覆い隠す設計になっている（TASK-90 AC #8 の根拠コメント参照）。
- ラベル文字色は src/labels.ts で暗色に固定されており、強調状態に依存しない。getLabelColor は d.kind だけで分岐する: BASE_LABEL_COLOR [40, 40, 40]、FIEF_LABEL_COLOR [74, 42, 130]（藍紫）、HRE_LABEL_COLOR [140, 30, 30]（臙脂）。
- halo は LABEL_OUTLINE_COLOR = [244, 236, 215]（クリーム）・LABEL_OUTLINE_WIDTH = 5 で全 TextLayer 共通（TASK-72 で背景パネルを撤去し halo 一本化）。halo も強調状態に依存しない。
- 概算コントラスト比: 羊皮紙下地 #f0e6cd 上にアクティブ塗りを合成すると約 (77, 129, 119)。これに対し国名の暗灰は約 3.3:1、諸侯領名の藍紫は約 2.4:1 で、大きめ文字の基準 3:1 すら下回る。ホバー前（alpha 128 で下地が透ける状態）ではいずれも大きく上回っていた。
- ラベルは TextLayer（layer_stack.ts の LABEL_LAYER_ID = power-labels ほか）としてポリゴンより上に描画されるため、これはレイヤー順序の問題ではなく色コントラストの問題である。

## 判断が要る点（実装時に決め、根拠を記録すること）

- 対処の方向: (a) アクティブ塗りの明度・alpha を調整して暗色ラベルの判読性を保つ、(b) 強調中だけラベルの文字色/halo を反転する（明色文字＋暗色 halo）、(c) 両者の併用。いずれでも TASK-90 AC #8（緑青が HRE 臙脂・諸侯領藍紫・河川赤茶と識別可能）と TASK-73 / TASK-74 の羊皮紙・褪せ顔料トーン方針を壊さないこと。
- 強調は勢力キー単位で飛び地を含む複数ポリゴンに同時に当たるため、ラベル側の切替判定も同じキー単位で行う必要がある。ホバー移動のたびにレイヤーを再構築しない変化検知（TASK-50 の規律、TASK-90 AC #7）を維持すること。
- アクティブ塗りの上には河川名・都市名ラベルも載りうる。今回の対象範囲に含めるかを決めること。
