## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
## 症状（bug）

**再現手順**: 年代を 1100 年（および 1000 年）にしてフランス北西部を表示する。

**期待挙動**: ノルマンディーがフランス王国領の一部としてではなく、ノルマン朝が
統治する公国として読み取れる。

**実際の挙動**: ノルマンディーが base の `Kingdom of France` ポリゴンに一括で
含まれており、フランス王国領として囲われて見える。

**発見契機**: ユーザーによる目視確認。

## 調査済みの事実

`europe_1100.geojson` の bbox 実測:

- `England`（SUBJECTO=England）: (-5.8, 50.0)-(1.7, 55.6) = **ブリテン島のみ**
- `Kingdom of France`（SUBJECTO=France）: (-2.6, 41.2)-(7.4, 51.4) = **ノルマンディーを含む**

1000 年も同じ構造。

`france_fiefs_flat_1000/1100.geojson` には既に `Duchy of Normandy` が収録されて
おり、諸侯領オーバーレイとしては区画が描かれている。問題は base の France
ポリゴンがその下にあること。

## 史実との照合（帰属先の判断に必要）

「イングランド領」とするのは年代によって成否が分かれる。

| 期間 | ノルマンディー公 | イングランド王 | 関係 |
| --- | --- | --- | --- |
| 1066〜1087 | ウィリアム 1 世 | 同一人物 | 同君 |
| 1087〜1106 | ロベール 2 世 | ウィリアム 2 世 → ヘンリー 1 世 | **分離**（兄弟が別々に統治） |
| 1106〜 | ヘンリー 1 世 | 同一人物 | タンシュブレーの戦いで統一 |

**1100 年ちょうどは分離期**で、ノルマンディー公ロベール 2 世とイングランド王
ヘンリー 1 世は別人。したがって単純に England 配下へ移すのも不正確で、
「ノルマン朝の一族が統治する半独立の公国（名目上の宗主はフランス王）」が実態に
近い。一方、フランス王国領として一括表示するのが不正確であることは確か
（カペー朝の実効支配はイル・ド・フランス周辺に限られ、ノルマンディーは 911 年の
サン・クレール・シュール・エプト条約以来、事実上独立した公国）。

1000 年も同様に、ノルマンディー公国は独立性の高い封土だった。

## 制約

base は `aourednik/historical-basemaps` のピン留めコミットから生成する上流データ
（`scripts/build-data.ts`、GPL-3.0）。**生成物の直接編集は再生成で失われる**ため、
パイプライン内の上書き、または幾何演算による切り出しで対応する。

## 方針の候補（実装時に判断）

1. **独立した公国として切り出す**（推奨）: `france_fiefs_flat_<year>` の
   `Duchy of Normandy` ポリゴンを使って base の `Kingdom of France` から差し引き、
   ノルマンディー公国の feature を立てる。幾何演算は TASK-92 で導入する差分演算と
   同じ道具が使える。名目上の宗主をフランス王とするか（`SUBJECTO = France`）、
   ノルマン朝の関係を表すかは表示上の意味づけとあわせて決める。
2. **宗主だけを補正する**: 幾何は変えず、諸侯領オーバーレイの
   `Duchy of Normandy` に宗主情報を持たせ、TASK-94 の外枠強調でイングランド側
   （あるいは独立）として囲う。base の塗りは France のまま残るので、
   「フランス領で囲われている」という見え方は完全には解消しない。
3. 上流データの粒度の限界として `data/known-limitations.json` に明記する
   （修正しない選択肢）。

同種の帰属の乖離は他にも見つかっており、横断的な監査は別タスク
（`.outputs/claude/base-territory-accuracy-survey.md` 参照）で扱う。
