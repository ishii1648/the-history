# 年代別の欠落勢力台帳（missing powers ledger）

19 のスナップショット年について「史実に存在したが、地図に独立ポリゴンとして
現れない勢力」を網羅的に記録する台帳（Issue #186）。実測は 2026-07-31、main =
`dd5ecd8` 時点のコミット済みデータに対して行った。

## 1. 目的と `known-limitations.json` との役割分担

| 文書                          | 役割                                                                                                                                        |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 本台帳（docs 側）             | **網羅**。開発者向けに、全年代の欠落・呑まれ・誤帰属を機械検証の結果とともに一覧し、是正タスクの起票と再検証の基準にする                    |
| `data/known-limitations.json` | **UI 表示分の抜粋**。情報パネルでユーザに説明する価値が高いものだけを選んで文章化する。台帳の行が抜粋済みの場合は「備考」列に該当 id を記す |

本台帳はデータ・コードを修正しない（Issue #186 のスコープ外）。是正は行ごとに
個別 issue を起票して行う。

## 2. 検証方法（再現手順）

3 つの機械検証を重ねた。いずれも `data/` のコミット済み生成物と OHM Overpass
だけを入力とし、スクリプトは使い捨て（本節の記述から再現できる）。

### 2.1 全レイヤーの年代別 NAME 全列挙

各年について、アプリが描画に使う 7 系統のファイル （`europe_<year>` /
`hre_<year>` / `hre_fiefs_flat_<year>` / `france_fiefs_flat_<year>` /
`italy_fiefs_flat_<year>` / `britain_fiefs_flat_<year>` /
`cliopatria_fiefs_flat_<year>`）の `features[].properties.NAME`
を集合化して列挙する。「その年、その名前の ポリゴンが 1
枚でも存在するか」の判定に使う。

### 2.3 OHM Overpass との突き合わせ（上流ソースの有無）

エンドポイントは既存パイプラインと同一 （`scripts/build-france-fiefs.ts` の
`OHM_SOURCE_URL` =
`https://overpass-api.openhistoricalmap.org/api/interpreter`）に `data=<query>`
を POST する。全欧 bbox の `boundary=administrative` は件数が多すぎるため、
Issue #186 の許容に従い**名前照合を台帳候補に絞った**。403 が返るため User-Agent
の付与が必要で、失敗時は 10 秒バックオフで 3 回まで再試行する （1
回目で成功）。クエリ:

```
[out:json][timeout:300];
(
  rel["boundary"="administrative"]["name:en"~"<候補名の正規表現>",i](34,-25,72,60);
  rel["boundary"="administrative"]["name"~"<候補名の正規表現>",i](34,-25,72,60);
);
out tags;
```

候補名の正規表現（2 回に分けて照会・計 429 リレーション取得）:

- 1 回目:
  `Brabant|Li[eè]ge|Trier|Palatinate|W[uü]rttemberg|Ragusa|Hospitaller|Knights of|Saint John|Courland|Transylvania|Epirus|Barcelona|Munster|Connacht|Connaught|Ulster|Ulaid|Tyrone|Salerno|Capua|Urbino|Bavaria|Moscow|Muscovy|Serbia|Rascia|Ra[sš]ka|Genoa|Sicily|Malta|Crete|Bohemia|Toulouse|Wallachia|Moldavia|Nemanji`
- 2 回目:
  `Saxony|Hesse|Electorate of Cologne|Electorate of Mainz|Archbishopric of Cologne|Archbishopric of Mainz|Apulia|Benevento|Naples|Duchy of Milan|Florence|Savoy|Siena|Lucca|Despotate|Duchy of Athens|Achaea|Candia|Salerno|Novgorod|Pskov|Montferrat|Leinster`

得られた各リレーションの `name:en` / `admin_level` / `start_date` / `end_date`
から「そのスナップショット年をカバーするリレーションが OHM
にあるか」を判定し、台帳の「上流」列に記載した。

## 3. 行の読み方（列と記号）

| 列         | 意味                                                                                                                                                                                                                                                                         |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 勢力       | 欠落している勢力（英語名は各データソースの表記に合わせる）                                                                                                                                                                                                                   |
| 存続       | 通説上の存続期間                                                                                                                                                                                                                                                             |
| 現状の塗り | §2.2 実測。その勢力の領域をいま覆っている表示（`base=` は `europe_<year>`、`overlay=` は諸侯領レイヤー）                                                                                                                                                                     |
| 型         | **完全欠落** = どのレイヤーにもポリゴンが無く領域が無塗りまたは別勢力 / **呑まれ** = 上位・包括勢力のポリゴンに含まれる / **誤帰属** = 史実と異なる別勢力の名前で塗られる / **過剰表示** = 当時存在しない勢力が描かれる。前後の年代で表示がある場合は「（退行）」を付す      |
| 上流       | OHM 実測。**○** = 該当年をカバーする `boundary=administrative` リレーションあり（OHM 実測の存続期間と rel id を併記）/ **△** = 同勢力の収録はあるが該当年をカバーしない / **✕** = OHM に収録なし = **ソース不在で当面埋まらない** / **—** = 今回の名前照合の対象外（未照会） |

補足: 1500〜1700 年の HRE 領邦は Roller データ（`hre_<year>`、CC BY-NC-SA）が 第
2 の上流になる。OHM に無くても Roller で表示できている勢力（トリーア・
プファルツ・ヴュルテンベルクなど）は該当年の行から外し、§4 の冒頭サマリに
記した。1000〜1492 年は Cliopatria（CC BY 4.0）も第 3 の上流になる。

### Issue #186 起票時の骨子からの差分（2026-07-31 実測で解消・変化した行）

- **1100 年プラハ・ブルノ**: `Duchy of Bohemia` として base + `hre_fiefs` に
  表示済み（#157 是正）。台帳から除外。**1200 年プラハは依然 `Poland` 塗り**
  （#157 は 1200 年のボヘミア本体を出典区画不在で見送り。`known-limitations` の
  `base-poland-paint-bohemia-1200` に記録済み）。
- **アイルランド東部**（レンスター・ミース＝東西ミース・ダブリン）: #172 で
  `britain_fiefs` に追加済み。欠落はマンスター・コナハト・アルスターのみ。
- **1600/1650/1700 年のアイルランド政体**（アイルランド王国・カトリック同盟）:
  #172 で表示済み。
- **トリーア選帝侯・プファルツ選帝侯・ヴュルテンベルク**: 骨子の「全期間不在」
  は誤り。1500〜1700 年は Roller 由来 `hre_<year>` で表示済み
  （`Archbishopric of Trier` / `Electorate of the Palatinate` /
  `Duchy of Württemberg`）。不在は 1000〜1492 年と 1715 年以降。
- **ボヘミア王国（1279〜1492）・バイエルン公領（1279〜1492）・
  ブランデンブルク**: Cliopatria 補完（#110 系）で表示済み。
- 骨子の「1200 セルビア消失・1400 モスクワ消失・1500 ジェノヴァ消失・ 1200
  バイエルン消失」「1650/1700 ベルギー = Luxembourg」「1880 クレタ =
  Bulgaria」「1914 のアルメニア・アゼルバイジャン・ジョージア過剰表示」は
  すべて現データでも再現した（各年の表を参照）。

## 5. 横断的な観察（是正タスク起票時の参考）

- **打ち切り空白は 2 箇所**: 1500 年のイタリア（`italy_fiefs` が 1492 で終了、
  Roller は帝国 13 領邦のみ）と 1715 年以降のドイツ（`hre_<year>` が 1700 で
  終了）。前者は OHM に該当年の上流（ジェノヴァ・ミラノ・シエナ・ルッカ等）が
  揃っており、後者も選帝侯領の過半は OHM にある（ザクセン・トリーア・
  ヴュルテンベルクが空白）。
- **ソース不在で当面埋まらない勢力（全照会で ✕）**: リエージュ司教領・
  トリーア選帝侯領（1500〜1700 の Roller を除く）・エピロス専制侯国・
  ウルビーノ公国・サレルノ侯国・ノルマン期アプーリア・マンスター／コナハト／
  アルスター諸王国・1200 年のボヘミア王国本体・1859 年以前のモルダヴィア・
  ウェールズ（1284〜1536）。
- **base の誤帰属で影響が大きいもの**: 1650/1700 年の南ネーデルラント一帯が
  `Luxembourg`、1815 年の同地域が `Austrian Empire`、1783 年のライン選帝侯領群
  （Prussia / Bavaria 塗り）、1100〜1200
  年の南イタリア（`Dutchy of
  Benevento`）、1880 年のクレタ（`Bulgaria`）。
- ラグーザ共和国は 1400〜1800 年の 7 スナップショットすべてで誤帰属または
  無帰属であり、塗られる勢力が年代ごとに変わる（Bosnia → Ottoman → Venice →
  Austrian Empire → 無帰属）。
