# バイエルン公領・ザクセン公領に他年ジオメトリの借用が適用できるかの調査

- 調査日: 2026-08-01
- 契機: ユーザー報告「バイエルン、ザクセン公領も同様の修正を適用できないか」
  （Issue #202 の手法が他へ広げられるかの検討。Issue が無い状態からの一次観測）
- 使用した手段: `data/*_<year>.geojson` 全レイヤーへの point-in-polygon 判定
  （代表 7 地点 × 全 19 スナップショット年）、OpenHistoricalMap Overpass API の
  全件走査（bbox 45.0,5.5,55.0,19.0・`admin_level` 2〜5・2,463 リレーション）
- 結論の反映先: Issue #209（1715 年ザクセン選帝侯領）/ Issue #203（借用方針の
  ADR）
- 関連する先行調査: `2026-08-01-austria-1492-missing.md`

## 結論

| 対象                                     | 欠落年      | 上流（OHM）                                    | 流用の可否                                             |
| ---------------------------------------- | ----------- | ---------------------------------------------- | ------------------------------------------------------ |
| ザクセン選帝侯領                         | **1715**    | 1423〜1485 / 1780〜1806（**1485〜1780 空白**） | **可（#202 と同型・最有力）**                          |
| バイエルン公領                           | **1200**    | 0962〜1100 / 1505〜1517（**1100〜1505 空白**） | 可だが条件付き（流用元は 1279 の Cliopatria 版に限る） |
| ザクセン公領（アスカーニエン家）         | 1200 / 1279 | 0804〜1180 のみ                                | **不可（史実に反する）**                               |
| マイセン辺境伯領                         | 1100〜1400  | 0965〜1002 のみ                                | **不可（領域が別物）**                                 |
| ブラウンシュヴァイク＝リューネブルク公領 | 1200〜1700  | 1235〜1269 のみ                                | ほぼ不可（別途調査）                                   |

## バイエルン

point-in-polygon（München / Regensburg）:

| 年                        | 担当レイヤー                                              | 状態                                           |
| ------------------------- | --------------------------------------------------------- | ---------------------------------------------- |
| 1000 / 1100               | `hre_fiefs`（OHM rel 2805255、0962〜1100）                | ○                                              |
| **1200**                  | —                                                         | **欠落**（base の Holy Roman Empire 一枚塗り） |
| 1279 / 1300 / 1400 / 1492 | `cliopatria_fiefs` の Duchy of Bavaria                    | ○                                              |
| 1500〜1700                | `hre_<year>`（Roller）                                    | ○                                              |
| 1715                      | `hre_fiefs`（OHM Electorate of Bavaria 1705-03-20〜1734） | ○                                              |
| 1783 以降                 | base の Bavaria                                           | ○                                              |

穴は 1200 年のみ。OHM は `Duchy of Bavaria` が 0962〜1100 の次が
1505-12-01〜1517 で **1100〜1505 が空白**。Cliopatria も 1200 年は帝国を 879,279
km² の一枚岩として モデル化し内部領邦を 1 件も持たない（`cliopatria_fiefs_1200`
はフランス諸侯 7 件のみ）。

流用元の選択が決定的:

| 候補                    | 面積       | bbox                        | 1200 年への妥当性                                                                                                                |
| ----------------------- | ---------- | --------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 1100 `hre_fiefs`（OHM） | 92,399 km² | (10.10,46.23)-(16.98,50.42) | **不可**。1180 年のゲルンハウゼン裁定以前の部族大公領で、オーストリア・シュタイアーマルク分離前の領域。1200 年に当てると過大表示 |
| 1279 `cliopatria_fiefs` | 35,213 km² | (7.02,47.27)-(12.78,50.18)  | 妥当。1180 年の再編後・ヴィッテルスバッハ家領                                                                                    |

ただし 1200 年の空白はバイエルン単独の問題ではない。既知の制限
`hre-fiefs-1200-core-missing` のとおり帝国領域の 81.3%（約 507,300
km²）が空白で、 バイエルンだけ埋めても 1200 年の見え方は本質的に変わらない。

## ザクセン（時代で 3 つに分かれる）

### (a) 1715 年のザクセン選帝侯領 — #202 と完全に同型

point-in-polygon（Dresden / Leipzig / Wittenberg）:

| 年          | 担当レイヤー                                                    | 状態                                                   |
| ----------- | --------------------------------------------------------------- | ------------------------------------------------------ |
| 1500〜1700  | `hre_<year>`（Roller。1700 は Electorate of Saxony 34,071 km²） | ○                                                      |
| **1715**    | —                                                               | **3 点とも欠落**（base の Holy Roman Empire 一枚塗り） |
| 1783 / 1800 | `hre_fiefs`（OHM rel 2806956、1780-03-31〜1806。37,078 km²）    | ○                                                      |
| 1815 以降   | base の Saxony                                                  | ○                                                      |

OHM は `Electorate of Saxony` が 1423〜1485 の次が 1780-03-31〜1806 で
**1485〜1780 が空白**。known-limitations の
`hre-fiefs-1715-1800-missing-territories` に「収録が 1554〜1780 年で途切れるため
1715 年に表示されず」と既記載。

流用元は 1700 年 `hre_1700.geojson` の `Electorate of Saxony`（15 年差）が妥当。
1697 年のポーランド王位兼任は同君連合で選帝侯領の領域は不変。1783 側（68 年差）
より近い。ライセンスは Roller = CC BY-NC-SA 4.0 で、流用先 `hre_fiefs_1715` の
CC0 系とは混在するため #202 と同じ扱いが要る。

### (b) 1200・1279 年のアスカーニエン家ザクセン公領 — 適用すべきでない

1180 年のゲルンハウゼン裁定で解体されたのは部族大公領で、公領自体はベルンハルト
3 世が エルベ川下流域の縮小領域で継承した。流用元の候補は 1100
年の部族大公領（OHM
0804〜1180）しかなく、それを当てると解体前の北ドイツ全域を描くことになり史実に反する。
1300 年の `Duchy of Saxe-Wittenberg` は 1296 年分裂後の片割れで、1200/1279 年の
公領（ヴィッテンベルク＋ラウエンブルク）とは別物。既知の制限
`hre-fiefs-saxony-successors-1200-1279` と #173 が扱う領域。

### (c) マイセン辺境伯領（Dresden / Leipzig）の 1100〜1400 — 適用すべきでない

OHM の `March of Meissen` は 0965〜0982 と 0982〜**1002** のみ。データ側も 1000
年に `hre_fiefs` で表示されるだけで、1100 / 1200 / 1279 / 1300 / 1400 の 5
年代連続で ドレスデン・ライプツィヒが帝国一枚塗りになる（1492 年に Cliopatria の
Electorate of Saxony が覆って復帰）。流用元が 1002 年の領域しかなく、東方植民で
大きく拡大した 1100〜1400 年に当てるのは無理。

## 付随発見: 1715 年は #187 の取りこぼしが複数ある

`hre_1700` にあり `hre_fiefs_1715` に無い勢力のうち、base
でも救われないもの（実測）:

| 勢力                 | 1715 の代表点の塗り                  | 上流                          |
| -------------------- | ------------------------------------ | ----------------------------- |
| ザクセン選帝侯領     | Dresden = Holy Roman Empire          | 1485〜1780 空白（**流用可**） |
| ヴュルテンベルク公領 | Stuttgart = Holy Roman Empire        | OHM は 1810 年以降のみ        |
| トリーア選帝侯領     | Trier = Holy Roman Empire            | OHM に収録なし                |
| プファルツ選帝侯領   | Heidelberg = base の Baden（誤帰属） | 分家のみ収録                  |

オーストリア大公領・ボヘミア王国も `hre_fiefs_1715` から落ちるが、base の
`Austrian Empire` が両点を覆うため帝国一枚塗りにはならない（ボヘミアを
「オーストリア帝国」名義で塗るのは 1715 年としては時代錯誤だが別論点）。

## 方針上の論点（#203 で ADR 化する）

known-limitations の該当エントリはいずれも

> 出典を持たない形状を合成しない本アプリの方針により、これらの空白はそのまま明示します

で締められている（decision-14 /
decision-18）。借用はこの方針の解釈に関わる判断で、 #203 が ADR
化する。本調査から #203 へ提供する材料:

- **同種の時間的転用は既に採用済み**である。`HRE_RANGE_OVERRIDES`
  （`scripts/build-hre.ts:154`）は Roller の `Bayern` を「1500 時点も 1623
  以降も 同一の中核領域で継続している」ことを根拠に 1500〜1806 へ、
  `albertinischesSachsennach1635` を 1572〜1806
  へ拡張している。`data/hre_1700.geojson` 自体も 1650 年の境界形状を 1700
  年として配信する外挿で、`src/config.ts` の `HRE_OVERLAY_YEARS`
  コメントに「領域継続性がある場合の近似延長」ポリシーとして
  明記されている。#202 で新しいのは転用が別ファイル間・別出典間にまたがる点
- 借用を認める条件は年差の上限だけでは足りない。**借用元と対象年の間に領域を変える
  事件が無いこと**が要る（1200 年のバイエルンに 1100 年の面を当てられないのは、
  間に 1180 年のゲルンハウゼン裁定があるため）
- 借用元のライセンス（Roller = CC BY-NC-SA 4.0 / Cliopatria = CC BY
  4.0）が流用先 ファイル（CC0 系）と混在する場合の出典表示。decision-2 が Roller
  の NC 条項を理由に
  ファイルを分離しているため、同一ファイルへの混在は認められない可能性が高い
